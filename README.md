# House Rent Frontend - React 🏠

A simple **House Rental Application Frontend** built using **React + Vite**.  
No backend, No HTML files. Only Frontend with fake data.

## 🚀 Features

- **User Authentication**: Register & Login pages
- **Home Page**: Shows near location rental houses - Pithapuram, Kakinada
- **Add House**: House owners can add new rental properties
- **View Details**: Click to see full house details with image, price, location
- **Dashboard/Profile**: See user information
- **Settings**: Logout, Change password options
- **Tenant View**: Separate view for tenants

## 🛠️ Tech Stack

- **Frontend**: React.js, Vite
- **Styling**: Inline CSS
- **Data**: Local dummyData.js - acts like fake database
- **Routing**: React State based routing - No React Router
